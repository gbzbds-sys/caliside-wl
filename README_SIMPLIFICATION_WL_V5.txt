CALISIDE WL V5 — FORMULAIRE SIMPLIFIÉ
======================================

Objectif : candidature rapide, non bloquante et moins personnelle.

NOUVEAU PARCOURS — 4 ÉTAPES
1. Informations essentielles
   - pseudo facultatif
   - âge facultatif
   - ID Discord requis uniquement pour créer le salon privé
   - FiveM facultatif
   - expérience RP facultative

2. Projet RP
   - idée de personnage/projet
   - type de RP (facultatif)
   - pourquoi CaliSide

3. RP
   - 2 questions seulement : Fear RP + Metagaming
   - 1 seule mise en situation : braquage à deux contre un

4. Envoi
   - créneau 1 facultatif
   - créneau 2 facultatif
   - aucun contrôle "date future"
   - aucune longueur minimum de réponse
   - case règlement non bloquante

VALIDATION
- Aucun minlength.
- Aucun nombre minimum de caractères.
- Aucun choix RP obligatoire.
- Aucun horaire obligatoire.
- Seul l'ID Discord doit être présent car il est techniquement nécessaire
  pour créer le salon Discord privé du candidat.
